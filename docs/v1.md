# V1 — Reliable Agent Runtime

V1 is a complete, provider-neutral core runtime. It demonstrates the production engineering boundary around an agent without claiming that a real LLM provider is already integrated.

## What V1 Demonstrates

- explicit task and execution state;
- validated state snapshots;
- structured tool definitions and input validation;
- runtime permission decisions;
- separate treatment of read and mutation tools;
- deterministic planner interface;
- bounded tool timeout and retry behavior;
- idempotency keys for side effects;
- versioned checkpoints and resume;
- chronological execution events;
- deterministic replay of the recorded trajectory;
- end-to-end tests for success, denial, timeout, recovery, idempotency, and replay.

## End-to-End Flow

    Task
      ↓
    Planner decision
      ↓
    Runtime policy
      ↓
    Tool validation
      ↓
    Retry / timeout boundary
      ↓
    Tool result
      ↓
    State transition + checkpoint
      ↓
    Trace events
      ↓
    Replay / inspection

## Deliberate V1 Boundary

The core runtime is provider-neutral. A real model gateway, model routing/fallback, prompt-injection defenses, API surface, telemetry export, and external evaluation integration remain later phases of the larger project. They are not represented as completed merely because the interfaces can be extended to support them.

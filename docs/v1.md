# V1 — Reliable Agent Runtime

V1 is a complete, provider-neutral core runtime. It demonstrates the production engineering boundary around an agent without claiming that a real LLM provider is already integrated.

## What V1 Demonstrates

- explicit task and execution state;
- validated state snapshots and transition rules;
- structured tool definitions, registry, and input validation;
- runtime permission decisions with mutation confirmation;
- deterministic planner contract;
- provider-neutral model completion boundary;
- bounded tool timeout and retry behavior;
- dependency circuit breaking;
- idempotency keys and duplicate-side-effect suppression;
- versioned checkpoints and resumable execution;
- chronological execution trace;
- separate structured audit records;
- deterministic replay of recorded trajectories;
- end-to-end tests for success, denial, confirmation, timeout, circuit breaking, recovery, idempotency, and replay.

## End-to-End Flow

    Task
      ↓
    Planner decision
      ↓
    Runtime policy
      ↓
    Tool validation
      ↓
    Circuit breaker
      ↓
    Retry / timeout
      ↓
    Tool result
      ↓
    State transition + checkpoint
      ↓
    Trace + audit
      ↓
    Replay / inspection

## Deliberate V1 Boundary

The core runtime is provider-neutral and uses in-memory implementations for state, checkpoints, trace, and audit. A concrete cloud model integration, model routing/fallback, response cache, prompt-injection defenses, durable persistence, external telemetry, HTTP API, and evaluation-harness integration belong to later phases.

Those later capabilities are intentionally not represented as completed merely because V1 provides clean interfaces for them.
